# Agent skills

Repository-owned skills for workflows that depend on Termy's public contracts.

- [`build-termy-plugins/`](build-termy-plugins/SKILL.md): build and validate
  Termy v1 TypeScript plugins.
- [`ghostty-to-termy/`](ghostty-to-termy/SKILL.md): convert Ghostty
  configuration into Termy configuration.

Keep these skills synchronized with the corresponding runtime, examples, and
public documentation when their contracts change.
